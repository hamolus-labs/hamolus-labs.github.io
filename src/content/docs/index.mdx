## What is Hamolus?

There is no application to fork. A Hamolus project is **assembled from parts** — a
core API worker, an admin console, panel apps, an MCP server for AI agents, seeds
and deployment presets.

<CardGrid stagger>
  <Card title="Core" icon="setting">
    A Hono API worker on Cloudflare Workers. Owns D1, KV, R2, auth, scope
    resolution and the metadata layer that makes collections dynamic.
  </Card>
  <Card title="Console" icon="puzzle">
    A SolidJS + StyleX admin SPA. Reads collection and panel metadata from the
    core — it is never rewritten by your project.
  </Card>
  <Card title="Panels" icon="list-format">
    Data-driven app surfaces generated from panel manifests, served with a typed
    client library and private asset URLs.
  </Card>
  <Card title="MCP" icon="rocket">
    A Model Context Protocol server for AI agents. Console-managed instances,
    per-user tokens, 42 static tools across four groups.
  </Card>
</CardGrid>

correction or a walkthrough is a contribution worth as much as a feature.
